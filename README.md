О проекте:
Интерактивная страница путешественника с управлением списком навыков через DOM API. Состояние (список навыков и выбранная тема) сохраняется в localStorage и восстанавливается при перезагрузке.

Как запустить
1. Откройте `index.html` 
2. Разрешите выполнение скриптов
3. В секции «Управление навыками» используйте кнопки

Структура проекта:
``` 
932401.sokolova.vika.lab5/
├── index.html
├── style.css
├── script.js
├── dom.js  
├── README.md
└── assets/
    └── avatar.png
``` 

Поиск элементов
getElementById - для списка навыков и кнопок
querySelector / querySelectorAll - для поиска <li> и <span> внутри них

Интерактивность
Кнопка «Добавить навык» - создание <li> с кнопкой «Удалить»
Кнопка «Очистить навыки» - удаляет все <li>, если список пуст — alert «Навыки уже удалены»
Кнопка «Переключить тему» - меняет класс theme-dark у <body>
Кнопка «Скрыть список навыков» - добавляет класс invisible, повторное нажатие возвращает видимость
